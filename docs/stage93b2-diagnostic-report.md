## 2. 错误集中在哪里

固定 0.5 仅用于描述错误方向。表中每格依次为误报按时、误报迟到、逐记录平均概率减真实标签。反转 262 条，正/负为 113/149。中断 318 条，正/负为 229/89。

| 模型 | 反转 0–25 ms | 中断 0–25 ms |
| --- | ---: | ---: |
| M1 · 当前概率 | 5 / 35 / −0.069 | 2 / 25 / −0.052 |
| M3 · Slack + SRTT | 37 / 13 / +0.047 | 74 / 1 / +0.139 |
| M4 · 加 RTTVAR | 32 / 13 / +0.047 | 74 / 1 / +0.138 |
| M5 · 加 InFlight | 28 / 14 / +0.038 | 70 / 3 / +0.135 |
| M6 · 加 CWND | 38 / 13 / +0.072 | 62 / 1 / +0.131 |

反转在 0–100 ms 的优势包含 M1 对较长预算正例的低估。25–50 ms 的 77 条全部按时，M1 的描述性 Brier 为 0.3703，M3 为 0.0103。回到 0–25 ms，M3 用更多误报按时换取较少漏判按时，Brier 点估计略差于 M1。M3 的 37 次误报按时有 28 次在 A 路，13 次误报迟到全部在 B 路。两条路径的误差方向不同，总体残差会抵消部分偏差。

中断中，M3 的 74 次误报按时有 72 次在 B 路。B 路平均残差 +0.308，A 路 −0.045。误报分布于高负载 34 次、低负载 40 次，普通事件 21 次、紧急事件 16 次、状态记录 37 次。全部 74 次发生在 5–15 ms 预算。Stage 9.2R 和 9.2R2 分别有 24、49 次，最早一批只有 7 条短预算记录。该偏差跨多个负载、任务及采集批次，但高度集中于路径和预算子层。中断涉及 A 路的配置变化，B 路的集中误报本身无法把原因归于中断时刻。

中断 0–25 ms 的 ROC-AUC 分别为 M3 0.9658、M1 0.9731，PR-AUC 分别为 0.9862、0.9838。M3 仍能有效排序，其高估按时概率是主要的可观测缺陷。反转的短预算 ROC-AUC 由 M1 的 0.9252 降至 M3 的 0.8919，排序差异也有贡献。 [按环境、连接种子、批次、路径、任务、负载及预算的误差与样本](../results/stage93b2/error_attribution.json)

## 3. 网络切换和状态新鲜度

独立校准档案的探针、内核丢包证据和稳定确认属于专门的校准运行。288 次 XQUIC Pilot 各有控制时间线和四份抓包，但没有可对齐同一连接的、已验证的实际切换或恢复边界。所有 1,688 条 0–100 ms 记录和 1,238 条 0–25 ms 记录的数据面阶段均为 **UNKNOWN**。稳定、切换前、过渡、切换后稳定、中断、恢复六组的可判定计数均为零。Stage 9.3-A 的配置时间段未用于阶段归因。 [既有数据面验收边界](stage92r2-targeted-closure-report.md#证据范围) · [同次运行证据清单](../results/stage93b2/transition_phase_coverage.json)

在可用的决策快照中，RTT 更新年龄大于 50 ms 的样本为反转 232/262、中断 269/318。该子组的 M3 − M1 为反转 −0.0204 [−0.0473, +0.0064]、中断 +0.0683 [+0.0385, +0.0965]。估计方向随环境变化。SRTT 上升时 M3 的逐记录平均残差为反转 +0.316（52 条）、中断 +0.115（130 条）。短预算可观测 PTO 均为零，最近丢包增量也只有零或缺失，无法据此评估恢复机制。状态新鲜度、SRTT 变化率、RTTVAR 变化量、交付采样年龄和路径排序均保留描述，观测关联无法区分真实时序滞后、不同路径的典型 RTT、队列或负载影响。新 Pilot 需把实际切换区间与最近 RTT 更新时间对齐，检验过渡期的旧样本是否系统性地导致高估。

## 5. 动态特征与覆盖

只使用预定义块和同一 L2 网格。交互假设为预算效应随 SRTT 或 RTT 年龄变化，以及同一 SRTT 水平下的变化率效应可能不同。前两项把 Slack 分解成按固定物理锚点加权的两个非负斜率分量，保持预算单调性。趋势交互与具有主效应的加性模型比较。训练折外初筛要求至少 80% 可用覆盖、两个训练环境都改善、等权 Brier 至少下降 0.005。所有块均未通过。共同训练样本的 M3 重拟合对照作为补充诊断，用于分离记录筛选与特征变化。

| 特征块 | 训练 OOF 结果与解释 |
| --- | --- |
| E1 · RTT 和交付采样新鲜度 | 覆盖 100%，两训练环境均未改善 |
| E2 · SRTT 变化率和 RTTVAR 变化量 | 覆盖 60.7%，两个训练域的配对降幅均低于 0.0003。旧中断完整子组看见改善，旧反转方向相反 |

## 6. 冻结的新开发 Pilot

计划使用真实 XQUIC 双路径和既有随机路径探索。训练环境为 A→B 延迟反转和客户端 A 路短中断；开发验证为 B→A 带抖动反转及服务端 B 路短中断。每个环境交叉两档负载和两个切换时点，安排稳定、切换前、边界附近、恢复附近及稳定后释放。生成预算固定为 12、18、24、32 ms。两分区使用独立的种子、工作负载 SHA-256、计划轨迹 SHA-256 和连接标识，另外检查历史复用和封存身份重叠。

历史 0–25 ms 的种子级 M3 − M1 配对标准差为反转 0.11388、中断 0.12668。以 95% 目标半宽 0.02 规划，公式 `ceil((1.96 × SD / 0.02)²)` 分别得到 125、155 个可用种子。按 80% 可用率预留、向上取整到四个等大条件，每环境固定 196 次，49 次/条件，合计 **784 次计划运行**。这是精度规划，阶段覆盖还需另验。每个适用阶段至少需 20 个有效种子和每类 20 条自然记录，切换目标样本中 UNKNOWN 不得超过 10%。原有环境总量、路径覆盖、自然负例与种子门槛沿用。每例只执行一次，保留失败，按清单停止。

采集前冻结 XQUIC 构建和验证器指纹。并行独立探针需与同次运行共用单调时钟，以双方向时延、排序、内核丢包及接收证据验证边界；连续新状态探针确认稳定，恢复也须独立验证。首个数据面变化及方向偏差沿用 5 ms 门槛，另核对探针扰动和 ±5% Goodput 等效预算。先验证探针和时钟映射，再执行冻结清单。当前完成的是设计和生成器，实际采集次数为零。 [固定清单、工作负载与轨迹指纹](../results/stage93b2/development_pilot_plan.json)

## 7. 复算和验收

用与 Stage 9.3-B 相同的 Python 3.12.3、NumPy 2.2.6、SciPy 1.15.3 环境。生成器在新的临时目录复核历史 A/B 结果，再生成 B2 文件。

```bash
python3 -m venv /tmp/iot-stage93b2
/tmp/iot-stage93b2/bin/python -m pip install -r evaluation/stage93b-requirements.txt
OPENBLAS_NUM_THREADS=1 /tmp/iot-stage93b2/bin/python -B tests/stage93b2_test.py
OPENBLAS_NUM_THREADS=1 /tmp/iot-stage93b2/bin/python -B evaluation/stage93b2.py /tmp/stage93b2-recomputed
diff -rq results/stage93b2 /tmp/stage93b2-recomputed
```

9 项新增测试和 82 项既有回归通过，0 项跳过。六份 B2 结果独立复算逐字节一致。离线结果描述随机探索中实际选中路径的交付概率，同连接内的记录相关，未选路径没有反事实标签。线上收益需要独立的端到端策略实验。
