# Stage 9.3-B · 开发集离线概率建模

**NO-GO，暂缓进入 Stage 9.3-C 的候选冻结准备。** Slack + SRTT（M3）在双路径反转环境的 0–100 ms 任务上优于两条概率基线。在单方向中断中，它对 Slack-only 的改善区间跨零，Brier 明显高于当前概率模型。两个环境最短预算区间的结果也支持保留当前概率模型作对照。M3 是后续机制诊断最值得保留的精简模型，当前没有模型通过晋级门槛。

## 1. 数据、标签与隔离

从 Stage 9.2、9.2R 和 9.2R2 原始档案重跑 Stage 9.3-A。全部 288 次连接通过既有归档和传输证据核对，四份 Stage 9.3-A JSON 与历史文件逐字节一致。运行时校验归档 SHA-256、选中路径标签和特征生成结果，另保存建模记录序列的哈希。48 条封存配置仅由既有 Oracle 检查隔离身份，执行数与封存结果读取数均为零。 [审计与数据指纹](../results/stage93b/cross_validation.json)

标签以接收端应用实际交付时刻对照有效截止。确认到期仍无交付或实际迟到为负例。无可判定证据的标签保留为空，本次回放的已提交记录中此类样本为零。监督行只使用提交后实际选中的路径，10,056 条未提交记录和未选候选路径均没有监督标签。4,315 条非正预算记录单独保留计数，全部为负例。另有 69 条已标注的预算大于 100 ms 记录，主模型在正且不超过 100 ms 的样本上拟合。

## 2. 模型与训练

| 模型 | 输入和变换 |
| --- | --- |
| M0 · Slack-only | 有效剩余预算 |
| M1 · Current Probability | 归档中的原始概率，直接评分 |
| M2 · Earliest Completion | 用归档的原始 `estimate_us` 计算 `Slack − estimate_us`，沿用既有离线裕量口径，以训练集逻辑映射获得概率 |
| M3 · Slack + SRTT | 同时拟合有效剩余预算和平滑 RTT |
| M4 · RTTVAR 消融 | M3 加 RTT 波动 |
| M5 · InFlight 消融 | M3 加在途字节 |
| M6 · CWND 消融 | M3 加拥塞窗口 |
| M7 · Full Network State | 沿用 9.3-A 的 15 维完整组合，使用完整样本 |
| D0、D1 · 诊断对照 | 分别用 SRTT 和 `Slack − SRTT` |

除固定 M1 外，模型最小化平均二项交叉熵加 `λ/2 × Σβ²`。惩罚只作用于标准化斜率，截距自由。均值与总体标准差在各折训练子集估计，常量列的尺度设为 1。Slack 和含 Slack 的单变量裕量系数下界为零。固定其余输入时，增加预算只会令概率不变或上升。缺失值按模型完整样本排除，训练维持实际类别比例。 [优化器说明](https://docs.scipy.org/doc/scipy-1.15.3/reference/optimize.minimize-lbfgsb.html)

按 `(环境, 连接种子)` 分 5 折，环境与采集批次内先打乱种子组再轮转，重复种子的所有记录同行。候选 `λ` 为 0.001、0.01、0.1、1。以训练环境等权、环境内种子等权的折外 Brier 选择，平分时取较强惩罚。全量开发训练中各拟合模型均选到网格下端 0.001。M0–M6 的拟合模型和 D0、D1 各使用 899 条记录（641 正、258 负，136 个种子组、144 次连接）。M7 使用 546 条（418 正、128 负，135 个种子组、143 次连接）。M1 直接应用于同样的 899 条训练域记录以核对可用性，无拟合参数。仅训练环境的折外 Brier 中，M6 为 0.0384，M3 为 0.0446，M0 为 0.1392。M6 的训练排名在验证中没有保持。 [固定配置](../configs/stage93b.json) · [折划分与选参](../results/stage93b/cross_validation.json) · [特征与参数](../results/stage93b/model_coefficients.json)

## 3. 验证指标与预算支持

主统计先在每个连接种子内平均记录损失，再对种子等权。配对差在同一条真实观测路径上计算，负值有利。区间按独立种子整体有放回重抽 4,000 次，模型固定。开发诊断区间采用逐项覆盖率。机器表同时给出逐记录等权 Brier 和 Log Loss、ROC-AUC 及以 Average Precision 计算的 PR-AUC。校准诊断在各验证环境拟合 `logit(Pr(Y=1 | p)) = intercept + slope × logit(p)`，拟合参数仅供评估。可靠性曲线采用十个固定概率箱，保留空箱。对数指标按既有口径截断至 `[10⁻⁶, 1−10⁻⁶]`，Brier 保留原始概率。 [Average Precision 定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html) · [完整指标及配对差](../results/stage93b/model_comparison.json) · [校准与可靠性曲线](../results/stage93b/calibration.json)

| 验证环境 | 0–100 ms 正/负 | 0–25 ms 正/负 | 25–50 ms 正/负 | 50–100 ms 正/负 |
| --- | ---: | ---: | ---: | ---: |
| 双路径反转 | 203/149 | 113/149 | 77/0 | 13/0 |
| 单方向中断 | 341/96 | 229/89 | 103/7 | 9/0 |

分层至少需要 20 个正例、20 个负例和 12 个种子组才给出分类、校准估计或损失区间。两个较宽预算段只报告描述性损失、标签及覆盖，不支持分类结论。在反转环境的 25–50 ms 中，77 条都是正例，M1 的描述性 Brier 为 0.3703，M3 为 0.0103。这部分正例上对 M1 的改善与 0–25 ms 持平的结果同时存在。

## 4. 增量特征与样本构成

| 消融 | 反转 0–100 ms ΔBrier [95%] | 中断 0–100 ms ΔBrier [95%] |
| --- | ---: | ---: |
| M4 − M3 · RTTVAR | −0.00093 [−0.00187, −0.00002] | +0.00003 [−0.00059, +0.00066] |
| M5 − M3 · 在途 | +0.0015 [−0.0040, +0.0072] | +0.0002 [−0.0047, +0.0050] |
| M6 − M3 · CWND | +0.0080 [+0.0016, +0.0146] | +0.0008 [−0.0066, +0.0082] |
| M7 − M3 · 全状态共同样本 | +0.0200 [−0.0038, +0.0481] | −0.0117 [−0.0269, +0.0037] |

RTTVAR 在反转 0–25 ms 上的改善为 0.0015，低于研究计划的 0.01 量级，也未在中断复现。InFlight 两环境的主范围差值都接近零，区间跨零。CWND 在反转中使概率误差增大，在中断的整体结果也无改善。0–25 ms 反转中 CWND 的 Brier 比 M3 高 0.0126，即使 PR-AUC 略高。

完整组合令共同样本仅保留反转的 164/352、中断的 256/437，正例率分别由 57.7% 升至 64.0%、由 78.0% 升至 82.8%。中断中，M3 在同一 256 条记录上的 Brier 为 0.0582，M7 为 0.0465，M1 为 0.0435。反转共同样本中，M3 为 0.1173，M7 为 0.1373。CWND 在中断共同样本有改善（−0.0123），全覆盖结果接近零，说明历史完整性筛选能改变观察结论。M7 的训练覆盖也下降，两个因素均需考虑。

以每个环境 68 个种子组计，M3 对 M0 在反转改善 57 组，在中断改善 36 组。逐个省去种子后，反转 ΔBrier 仍不高于 −0.1017，中断仍为负，但 Bootstrap 区间反映种子间差异。RTTVAR 在反转各有 34 个种子改善和变差。表中不把小幅平均变化解释成普遍收益。 [共同样本、覆盖及逐种子影响](../results/stage93b/feature_ablation.json)

400 次训练 Bootstrap 在环境内重抽种子并重拟合缩放和参数，固定交叉验证选出的惩罚强度。9 个拟合模型共 3,600 次均完成。M3 的标准化 Slack 系数 6.281 [5.486, 6.983]，SRTT 为 −2.240 [−2.581, −1.959]。M4 的 RTTVAR 系数 0.220 [−0.385, 0.871]，M5 的在途系数 −0.226 [−0.515, 0.021]，M6 的 CWND 系数 −0.766 [−1.015, −0.584]。原始单位系数、截距、缩放量和符号稳定性一并保存。SRTT、RTTVAR 与传输状态共享变化，系数是条件关联，尤其是稳定的负 CWND 系数与验证误差上升可以同时出现。 [参数与训练重抽样](../results/stage93b/model_coefficients.json)

## 5. 批次与 Slack–SRTT 诊断

三个端点二进制的 SHA-256 前缀为 `470418e9`、`d8eebaa2`、`ec0a2518`。批次剔除分析在训练端重跑分组交叉验证，也单列固定模型的验证端剔除和每批结果。下表给出 0–100 ms 的 M3 − M0，括号为两端都剔除该批次时的结果。

| 排除批次 | 双路径反转 | 单方向中断 |
| --- | ---: | ---: |
| Stage 9.2 | −0.1060（−0.1128） | −0.0125（−0.0138） |
| Stage 9.2R | −0.1065（−0.0947） | −0.0228（−0.0085） |
| Stage 9.2R2 | −0.1011（−0.1031） | −0.0075（−0.0183） |

M3 对 M0 的反转收益在剔除大批 9.2R2 后仍在。但同时剔除该批次时，M4 − M3 变为反转 +0.0019、中断 +0.0029，增量方向反转。仅看 9.2R2 的反转样本，M5 − M3 为 −0.0072，9.2R 为 +0.0098。中断的 CWND 效应在排除不同训练批次后约为 −0.0118 至 +0.0114。9.2 单批验证只有反转 26 条和中断 30 条，支持不足。二进制、负载与预算覆盖随批次共同变化，批次差异无法归因给二进制本身。 [批次结果与折内重拟合](../results/stage93b/batch_sensitivity.json)

两变量 M3 在两环境的 0–100 ms 和 0–25 ms 上均优于单独 SRTT（D0）和固定裕量 `Slack − SRTT`（D1）的概率误差。D1 在中断 0–25 ms 上 ROC-AUC 为 0.9672，Brier 却为 0.2257。SRTT 反映平滑往返时延，固定裕量只是启发式。按 SRTT 区间查看 Slack，反转中 SRTT >60 ms 时，0–10 ms 的按时比例为 1/34，10–15 ms 为 11/71，20–25 ms 为 13/27。按 Slack 区间查看 SRTT，中断的 10–15 ms 内，SRTT ≤15 ms 为 69/71，15–30 ms 为 41/86。M3 在后一格平均预测约 0.84，实际约 0.48，暴露了中断环境中的校准偏差。这些格子是局部描述，细分后的少数类与种子支持大多不足。 [Slack 与 SRTT 交叉表](../results/stage93b/feature_ablation.json)

## 6. 阶段判定与适用范围

阶段门槛在本轮验证评分前固定。精简候选须在两环境的 0–100 ms 上分别对 M0 与 M1 降低至少 0.01 Brier，且配对区间上界小于零。0–25 ms 对两基线须保持点估计优势，排除任一训练批次后对 M0 的主范围方向须保持。M3–M6 均未通过，主要失败条件是中断环境对 M1 的概率误差及反转最短预算的优势缺失。M3 可继续用于定位短预算校准偏差及机制依赖。M4 的增量过小且受批次影响，M5、M6 没有跨环境的正向增量证据，M7 只作覆盖受限的探索。 [机器判定](../results/stage93b/model_comparison.json)

结论适用于两个训练环境和两个开发验证环境的实栈随机路径数据，标签条件为已提交且只有实际选择路径可观测。前序路径分配会改变后续状态，同连接记录相关。离线概率误差衡量的是对已观测路径的预测，验证线上事件按时率需要独立的端到端策略实验。当前证据应优先用于中断短预算的校准诊断及补齐过渡状态样本。
